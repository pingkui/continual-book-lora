| Component | Use | Licence |
|---|---|---|
| Qwen/Qwen2.5-7B-Instruct (pinned revision) | base model; also the only teacher (writes all training rows locally) | Apache-2.0 |
| CPython 3.12 (python-build-standalone, astral-sh) | env/python.tar.gz, the interpreter | PSF-2.0 (CPython), MIT (build scripts) |
| jax, jaxlib, jax-cuda12-plugin, jax-cuda12-pjrt | training and generation | Apache-2.0 |
| optax | optimizer | Apache-2.0 |
| torch | eigendecompositions for the protection subspaces; export | BSD-3-Clause |
| transformers, huggingface_hub, safetensors, datasets, tokenizers | tokenizer, base download, checkpoint export | Apache-2.0 |
| numpy | host arrays | BSD-3-Clause |
| ml_dtypes | bf16/fp16 host arrays | Apache-2.0 |
| NVIDIA CUDA runtime libraries (nvidia-*-cu12 wheels) | GPU kernels for jax and torch | NVIDIA EULA (redistributable runtime) |
| data/general_ru.json: 340 paragraphs from Russian Wikipedia | general-text protection subspace (not training targets) | CC BY-SA 4.0, attribution: Wikipedia contributors |

No dataset other than the book itself and the shipped Wikipedia paragraphs is used. No row is generated by an
Anthropic Claude model or by any API; the teacher is the pinned base running inside run.sh.
